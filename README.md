Removes preinstalled Windows bloatware, disables telemetry, and cleans up the Start Menu with a single PowerShell script. Supports Windows 10 and 11 including the latest 24H2.

## Features

- Removes 40+ preinstalled apps (Xbox, Cortana, Teams, mixed reality)
- Disables Windows telemetry and data collection
- Cleans Start Menu tiles and taskbar pinned apps
- Optional: disable Bing search in Start Menu
- Selective mode — choose exactly what to remove

## FAQ

**Can it break Windows Update?**  
No. The script does not touch Windows Update. It removes user-facing bloat apps only.

**Can I restore removed apps later?**  
Most removed apps can be reinstalled from the Microsoft Store. Use the included restore script for bulk restoration.

## Requirements

- Windows 10 / 11 (64-bit)
- Run as Administrator. PowerShell execution policy may need to be temporarily unlocked
- Administrator rights
